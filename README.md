# JavaScript Core Concepts & Todo Application

A repository demonstrating core JavaScript development concepts alongside a dynamic, interactive front-end web application. The project is split into two main sections: a foundational suite of 10 utility tasks (covering logic, arrays, and functions) and a structural Object-Document Model (DOM) application.

## 🛠️ Tech Stack

*   **Frontend Environment:** HTML5, CSS3
*   **Core Language:** JavaScript (ES6+)
*   **Mechanics:** DOM Manipulation, Event Listeners, Dynamic Element Creation

## 🚀 Repository Contents & Features

### 1. Interactive Todo Application
A complete task-tracking web tool utilizing native browser inputs and DOM injections to deliver real-time item management:
*   **Dynamic Addition:** Instantly generates interactive list items (`<li>`) from user text field input.
*   **Input Validation:** Features structural defensive checks ensuring empty elements cannot pollute the list state.
*   **Granular Control:** Individual delete mapping allows removing individual, targeted list items dynamically.
*   **Batch Action:** Single-click canvas cleanup provides an option to completely reset the DOM workspace instantly.

### 2. Foundational JavaScript Lab Exercises
A curated suite of core algorithmic structures covering foundational programming milestones:
*   **Task 01: Basic Calculator** — Captures numbers via prompt utilities to execute operational tracking (+, -, \*, /).
*   **Task 02: Even or Odd Evaluator** — Validates integers using modulo checking constraints.
*   **Task 03: Voting Verification Engine** — Evaluates user age parameters against constitutional thresholds ($age \ge 18$).
*   **Task 04: Linear Array Accumulator** — Iterates over a flat numbers matrix via standard loop constructs to produce aggregate summaries.
*   **Task 05: String Palindrome Asserter** — Evaluates input strings against structural character reversals.
*   **Task 06: Ternary Largest Value Extractor** — Accepts multi-variable numeric inputs and flags maximum bounds.
*   **Task 07: Bounded Range Sequencer** — Runs boundary loops (1 to 20) to extract isolated arithmetic integers.
*   **Task 08: Mathematical Factorial Engine** — Employs loop accumulators to calculate exact sequential product values.
*   **Task 09: Structural Array Reverser** — Traverses dataset indices in descending sequence matrices.
*   **Task 10: Structural Security Strength Asserter** — Validates string boundaries against minimum length criteria.
